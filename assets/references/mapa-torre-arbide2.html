Notas del prototipo: las coordenadas de la torre son las reales; las de los puntos de interés (PUNTOS_DE_INTERES en el script) siguen siendo de EJEMPLO — reemplázalas por las reales. El ruteo usa el servidor demo público de OSRM (gratis, sin API key) vía Leaflet Routing Machine; para producción con tráfico real se recomienda apuntar a tu propia instancia de OSRM o a OpenRouteService (gratis hasta 2,000 requests/día). El Street View usa el embed gratuito de Google Maps (sin API key ni facturación) — cada POI necesita su propio link streetViewEmbed generado a mano desde Google Maps (ver comentario junto a PUNTOS_DE_INTERES).
